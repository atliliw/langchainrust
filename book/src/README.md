# LangChainRust

A LangChain-inspired Rust framework for building production LLM applications:
agents, RAG, memory, MCP, A2A, guardrails, evaluation, and LangGraph workflows —
all in pure Rust.

## Start here

- [Quick Start](quick-start.md) — a working agent in 5 minutes (Rust or Python)
- [Installation](installation.md) — versions, feature flags, MSRV
- [Agents](agents.md) — function calling, ReAct, planning, subagents
- [MCP Protocol](mcp.md) — client, server, 2026-07-28 compliance
- [OpenAI-Compatible Server](openai-server.md) — call the runtime from any SDK
- [Evaluation](evaluation.md) — evaluators, verifiers, regression gates

## Why this framework

- **Pure Rust** — one binary, no Python runtime
- **Production-first** — durable execution, approvals, budgets, guardrails, audit
- **Protocol-complete** — MCP, A2A, and an OpenAI-compatible endpoint
- **Verifiable** — evaluators, verifiers, regression gates

LangChainRust 使用指南

LangChainRust 是一个 Rust 实现的 LangChain 框架，用于构建 LLM 应用。

核心功能包括：
1. LLM 调用（OpenAI、Ollama）
2. Agent 智能代理
3. Memory 对话记忆
4. RAG 检索增强生成
5. BM25 关键词检索
6. Hybrid 混合检索

安装方式：
在 Cargo.toml 中添加依赖：
langchainrust = "0.2.6"

快速开始示例：
use langchainrust::OpenAIChat;
let llm = OpenAIChat::new(config);
let response = llm.chat(messages).await?;

更多详情请参考 USAGE.md 文档。

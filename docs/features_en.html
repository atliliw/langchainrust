Agents

Agent is LangChainRust's core component that enables LLMs to autonomously decide, call tools, and execute multi-step tasks.

Core value: Break complex problems into steps, automatically select appropriate tools, iterate until task completion.

Autonomous Decision

Agent decides next action based on question and tool descriptions

Tool Calling

Calculator, DateTime, URLFetch and more

Iterative Execution

Observe tool output and continue thinking

Type Safety

FunctionCallingAgent uses native FC

FunctionCallingAgent (Recommended)

Use Case

Models supporting Function Calling (GPT-4, Claude, Gemini, etc.)

rust 
use langchainrust::{
    FunctionCallingAgent, AgentExecutor, BaseAgent, BaseTool,
    OpenAIChat, OpenAIConfig, Calculator, DateTimeTool,
};

let config = OpenAIConfig {
    api_key: std::env::var("OPENAI_API_KEY")?,
    model: "gpt-4".to_string(),
    ..Default::default()
};
let llm = OpenAIChat::new(config);

let tools: Vec> = vec![
    Arc::new(Calculator::new()),
    Arc::new(DateTimeTool::new()),
];

let agent = FunctionCallingAgent::new(llm, tools.clone(), None);
let executor = AgentExecutor::new(Arc::new(agent), tools)
    .with_max_iterations(5);

let result = executor.invoke("Calculate 37 + 48").await?;

Chains

Chain is LangChain's core abstraction that combines Prompt, LLM, Memory into a processing pipeline.

LLMChain

Basic Chain: Prompt + LLM

SequentialChain

Execute multiple Chains sequentially

ConversationChain

Chat Chain with Memory

LLMChain Example

rust 
use langchainrust::{LLMChain, BaseChain};

let chain = LLMChain::new(llm, "Explain in one sentence: {topic}");

let inputs = HashMap::from([
    ("topic", Value::String("Rust language".to_string()))
]);

let result = chain.invoke(inputs).await?;

Memory

Memory manages Agent or Chain conversation history, controlling Token consumption.

MemoryCompressionToken ControlUse Case
BufferMemoryNo compressionUnlimitedShort conversations
WindowMemoryWindow truncationFixed k roundsSimple control
SummaryMemoryLLM summarySmart compressionLong conversations
SummaryBufferMemorySummary + retainDynamicRecommended

ConversationBufferMemory

rust 
let mut memory = ConversationBufferMemory::new();

let inputs = HashMap::from([("input", "My name is John")]);
let outputs = HashMap::from([("output", "Hello John!")]);
memory.save_context(&inputs, &outputs).await?;

let vars = memory.load_memory_variables(&HashMap::new()).await?;
// Output: "Human: My name is John\nAI: Hello John!"
⚠️ SummaryMemory Cost Warning

Each conversation round calls LLM for summary. 100 rounds = 100 LLM calls. Evaluate costs carefully.

Custom Tool

rust 
use langchainrust::core::tools::{BaseTool, ToolError};
use schemars::JsonSchema;
use serde::Deserialize;

#derive[JsonSchema, Deserialize]
struct WeatherInput { city: String }

pub struct WeatherTool;

#async_trait
impl BaseTool for WeatherTool {
    fn name(&self) -> &str { "weather" }
    
    fn description(&self) -> &str {
        "Query city weather"
    }
    
    async fn run(&self, input: String) -> Result<String, ToolError> {
        let args: WeatherInput = serde_json::from_str(&input)?;
        Ok(format!("{} weather: Sunny, 25°C", args.city))
    }
}

RAG

RAG retrieves relevant documents from knowledge base first, then lets LLM generate answers based on retrieved content.

Core value: Let LLM access private knowledge base and latest data without retraining.

Document Loading

PDF, CSV, and more

Smart Splitting

RecursiveCharacterSplitter

Vector Embedding

OpenAI Embeddings

Semantic Retrieval

Vector similarity based

Complete RAG Workflow

rust 
use langchainrust::{
    Document, InMemoryVectorStore, MockEmbeddings,
    SimilarityRetriever, RecursiveCharacterSplitter,
};

// 1. Prepare documents
let docs = vec![
    Document::new("Rust is a systems programming language..."),
];

// 2. Split documents
let splitter = RecursiveCharacterSplitter::new(200, 50);
let chunks = splitter.split_documents(&docs)?;

// 3. Create retriever
let retriever = SimilarityRetriever::new(store, embeddings);
retriever.add_documents(chunks).await?;

// 4. Execute QA
let qa_chain = RetrievalQA::new(llm, retriever, 3);
let result = qa_chain.invoke(inputs).await?;

ParameterRecommendedDescription

Prompts

PromptTemplate and ChatPromptTemplate provide dynamic Prompt construction with variable placeholders.

PromptTemplate

rust 
use langchainrust::prompts::PromptTemplate;

let template = PromptTemplate::new("Explain {topic} in {style} style");

let vars = HashMap::from([
    ("style", "concise"),
    ("topic", "Rust ownership"),
]);

let prompt = template.format(&vars)?;
// "Explain Rust ownership in concise style"

ChatPromptTemplate

rust 
let template = ChatPromptTemplate::new(vec![
    Message::system("You are a {role}, expert in {domain}."),
    Message::human("Hello, I'm {name}."),
    Message::human("{question}"),
]);

let messages = template.format(&vars)?;

Best Practices

01 Agent Selection

Use FunctionCallingAgent first (more reliable). Use ReActAgent for local models.

02 Model Selection

Agents: gpt-4 recommended. Simple chat: gpt-3.5-turbo.

03 Memory Selection

Long conversations: SummaryBufferMemory. Short: BufferMemory.

04 RAG Config

chunk_size=200-500, overlap=50-100, top_k=3-10

05 Streaming

Use stream_chat() for interactive scenarios to reduce perceived latency.

06 Security

Use environment variables for API keys. Never hardcode.

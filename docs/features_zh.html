Agents（智能代理）

Agent 是 LangChainRust 的核心组件，让 LLM 能够自主决策、调用工具、执行多步骤任务。

核心价值：将复杂问题分解为步骤，自动选择合适工具，迭代执行直到完成任务。

自主决策

根据问题内容和工具描述自主决定下一步动作

工具调用

Calculator、DateTime、URLFetch 等内置工具

迭代执行

观察工具输出后继续思考直到得出答案

类型安全

FunctionCallingAgent 使用原生 FC

FunctionCallingAgent（推荐）

适用场景

支持 Function Calling 的模型（GPT-4、Claude、Gemini 等）

rust 
use langchainrust::{
    FunctionCallingAgent, AgentExecutor, BaseAgent, BaseTool,
    OpenAIChat, OpenAIConfig, Calculator, DateTimeTool,
};

let config = OpenAIConfig {
    api_key: std::env::var("OPENAI_API_KEY")?,
    model: "gpt-4".to_string(),
    ..Default::default()
};
let llm = OpenAIChat::new(config);

let tools: Vec> = vec![
    Arc::new(Calculator::new()),
    Arc::new(DateTimeTool::new()),
];

let agent = FunctionCallingAgent::new(llm, tools.clone(), None);
let executor = AgentExecutor::new(Arc::new(agent), tools)
    .with_max_iterations(5);

let result = executor.invoke("计算 37 + 48").await?;

ReActAgent（兼容旧模型）

适用场景

不支持 Function Calling 的模型（开源模型、本地部署模型）

rust 
let tools: Vec> = vec![
    Arc::new(Calculator::new()),
    Arc::new(DateTimeTool::new()),
];

let agent = ReActAgent::new(llm, tools.clone(), None);
let executor = AgentExecutor::new(Arc::new(agent), tools)
    .with_max_iterations(5);

两种 Agent 对比

维度FunctionCallingAgentReActAgent
工具调用原生 Function Calling文本解析（正则）
可靠性高（类型安全）中
Token 消耗低高
适用模型GPT-4 / Claude / Gemini所有模型
推荐指数★★★★★★★★

Chains（链式调用）

Chain 是 LangChain 的核心抽象，将 Prompt、LLM、Memory 等组件串联成处理管道。

LLMChain

最基础的 Chain，组合 Prompt + LLM

SequentialChain

顺序执行多个 Chain

ConversationChain

带 Memory 的对话 Chain

RetrievalQA

RAG Chain

LLMChain 示例

rust 
use langchainrust::{LLMChain, BaseChain};

let chain = LLMChain::new(llm, "请用一句话解释：{topic}");

let inputs = HashMap::from([
    ("topic", Value::String("Rust 语言".to_string()))
]);

let result = chain.invoke(inputs).await?;

Memory（对话记忆）

Memory 管理 Agent 或 Chain 的对话历史，控制 Token 消耗。

Memory压缩方式Token 管理适用场景
BufferMemory无压缩无限制短对话
WindowMemory窗口截断固定k轮简单控制
SummaryMemoryLLM摘要智能压缩长对话
SummaryBufferMemory摘要+保留动态推荐

ConversationBufferMemory

rust 
let mut memory = ConversationBufferMemory::new();

let inputs = HashMap::from([("input", "我叫张三")]);
let outputs = HashMap::from([("output", "你好张三！")]);
memory.save_context(&inputs, &outputs).await?;

let vars = memory.load_memory_variables(&HashMap::new()).await?;
// 输出: "Human: 我叫张三\nAI: 你好张三！"
⚠️ SummaryMemory 成本注意

每轮对话都会调用 LLM 生成摘要。100轮对话 = 100次 LLM调用，需评估成本。

Tools（工具系统）

Tool 是 Agent 可以调用的外部函数，用于执行具体操作（计算、查询、抓取等）。

工具描述参数
Calculator数学表达式计算expression
DateTimeTool日期时间查询operation, datetime
SimpleMathTool高级数学运算operation, value
URLFetchTool网页抓取operation, url

自定义工具

rust 
use langchainrust::core::tools::{BaseTool, ToolError};
use schemars::JsonSchema;
use serde::Deserialize;

#derive[JsonSchema, Deserialize]
struct WeatherInput { city: String }

pub struct WeatherTool;

#async_trait
impl BaseTool for WeatherTool {
    fn name(&self) -> &str { "weather" }
    
    fn description(&self) -> &str {
        "查询城市天气"
    }
    
    async fn run(&self, input: String) -> Result<String, ToolError> {
        let args: WeatherInput = serde_json::from_str(&input)?;
        Ok(format!("{}天气：晴，25°C", args.city))
    }
}

RAG（检索增强生成）

RAG 先从知识库检索相关文档，再让 LLM 基于检索内容生成答案。

核心价值：让 LLM 访问私有知识库、最新数据，无需重新训练模型。

文档加载

支持 PDF、CSV 等格式

智能分割

RecursiveCharacterSplitter

向量嵌入

OpenAI Embeddings

语义检索

基于向量相似度

完整 RAG 流程

rust 
use langchainrust::{
    Document, InMemoryVectorStore, MockEmbeddings,
    SimilarityRetriever, RecursiveCharacterSplitter,
};

// 1. 准备文档
let docs = vec![
    Document::new("Rust 是一门系统编程语言..."),
];

// 2. 分割文档
let splitter = RecursiveCharacterSplitter::new(200, 50);
let chunks = splitter.split_documents(&docs)?;

// 3. 创建检索器
let retriever = SimilarityRetriever::new(store, embeddings);
retriever.add_documents(chunks).await?;

// 4. 执行问答
let qa_chain = RetrievalQA::new(llm, retriever, 3);
let result = qa_chain.invoke(inputs).await?;

RAG 配置建议

参数推荐值说明
chunk_size200-500每个 chunk 的最大字符数
overlap50-100相邻 chunk 的重叠字符数
top_k3-10检索返回的文档数量

Prompts（提示词模板）

PromptTemplate 和 ChatPromptTemplate 提供动态 Prompt 构建。

PromptTemplate

rust 
use langchainrust::prompts::PromptTemplate;

let template = PromptTemplate::new("请用{style}风格解释{topic}");

let vars = HashMap::from([
    ("style", "简洁"),
    ("topic", "Rust所有权"),
]);

let prompt = template.format(&vars)?;
// "请用简洁风格解释Rust所有权"

ChatPromptTemplate

rust 
let template = ChatPromptTemplate::new(vec![
    Message::system("你是一个{role}，专精于{domain}。"),
    Message::human("你好，我是{name}。"),
    Message::human("{question}"),
]);

let messages = template.format(&vars)?;

最佳实践

01 Agent 选择

优先使用 FunctionCallingAgent（更可靠），本地模型用 ReActAgent

02 模型选择

Agent 推荐 gpt-4，简单对话用 gpt-3.5-turbo

03 Memory 选择

长对话用 SummaryBufferMemory，短对话用 BufferMemory

04 RAG 配置

chunk_size=200-500，overlap=50-100，top_k=3-10

05 流式输出

交互场景使用 stream_chat()，降低感知延迟

06 安全提示

API Key 使用环境变量，不要硬编码
